# MyDVD

MyDVD 是一个独立维护的 Android 手机端影片浏览和播放工程。它保留分类、搜索、详情、线路选择、在线播放等功能，并在影片详情页加入按剧集选择的批量下载。

## 使用

首次启动会载入用户指定的 [默认源配置](https://raw.githubusercontent.com/qist/tvbox/refs/heads/master/0821.json)。也可以在设置中更换或添加源。搜索并打开影片后，详情页的“批量下载”可勾选剧集，并可在弹窗里全选或反全选；“下载管理”逐条展示队列和进度，可设置同时下载 1～10 个任务（默认 1 个），顶部可全部开始或全部暂停。全部开始会继续已暂停任务并重试失败任务；每条任务也可单独暂停、继续或失败重试，右侧垃圾桶可删除该任务及其已下载的完整或部分文件。暂停一条任务不会停止队列中的其他任务。Android 10 及以上的新导出位置是系统 **下载/MyDVD** 文件夹；Android 7 至 9 保存在应用专属下载目录。

源配置成功刷新后会保存解析所需的本地副本和独立的刷新时间。启动或切换到已有源时，若上次成功刷新不足一天且本地副本及爬虫 JAR 可用，就直接从本地载入源配置；首次添加、上次刷新已满一天、手动刷新或本地副本失效时才重新请求源配置。启动时会先从本地副本恢复片源列表和上次选择的子源，使缓存首页显示后即可切换栏目；已有同一源和首页片源的首页记录也会先显示，首页影片数据仍会按片源请求更新。图片地址带有不可用的非标准端口时，封面加载会尝试该域名的标准 HTTP/HTTPS 端口。

下载会先解析该集的播放地址，再处理直链 MP4 或已结束的 HLS 播放列表。HLS 的 TS 或 fMP4 分段通过系统 MediaExtractor 和 MediaMuxer 封装为 MP4，不重新编码。遇到 HLS 时间轴切换时，下载器按切换点分段重建时间戳，并检查轨道和编码参数；实际发生不兼容变化时会说明无法合并为单个 MP4。对于视频轨道缺少 H.264/H.265 编码配置的情况，会从视频样本提取 SPS/PPS（以及 H.265 的 VPS）补入 MP4 轨道；封装失败会显示具体轨道或系统封装错误。AES-128 HLS 可以解密；DRM、直播、分离音轨、字节范围分段等目前会在任务中显示失败原因。输出是否可用还取决于源站返回的数据、设备支持的编码和可用存储空间。

默认 EXO 播放器的在线播放、磁盘预载与批量下载共用同一份持久磁盘缓存。下载正在播放的剧集时，任务会优先沿用正在播放的地址和请求头，从已有字节继续读取缺失部分；如果源站给出不同的临时地址，可能无法复用旧地址的缓存。MPV/IJK 内核目前仍使用各自的网络和缓存链路，完整共用以 EXO 内核为准。

下载未完成时，下载管理的“播放页”只打开影片详情页，不直接播放下载临时文件。播放页会重新解析在线播放地址；若使用 EXO 且地址与已缓存的资源相同，播放时会先读取共享缓存中已经写入的字节，再联网请求缺失部分。下载临时文件尚未导出成 MP4 前不会作为本地视频被播放。不同临时地址或 MPV/IJK 内核可能重新请求视频数据。

下载完成并导出 MP4 后，影片页打开同一片源、同一影片、同一线路和同一集时，会优先读取本地 MP4；从下载管理返回时，正在播放的同一集网络流会在保留播放位置的情况下切换为本地文件，标题标注“已下载”。如果文件已被手动删除或移动，则继续使用在线播放。拖动本地 MP4 的进度不会为视频重新联网；EXO 读取本地文件时也不会把整个 MP4 再写入播放缓存。在线播放产生的原始缓存与导出的 MP4 分开保存，缓存仍按设置上限清理。

缓存默认上限为 512 MB。从首页“更多”菜单或“设置”页可直接进入“下载管理”和“播放缓存管理”；下载管理页也保留缓存管理入口。两个列表会显示记录来源片源，并可打开原影片播放页；当前源配置或所选片源不符时会先提示，旧版无来源信息的缓存无法定位。播放缓存管理页可调整上限、查看各影片占用，并分别删除历史影片缓存。达到上限后，按整部影片的最近使用时间清理；正在播放或被未完成下载任务使用的影片不会清理，因此全部缓存都处于使用中时可能暂时超出上限，待使用结束后再收缩。手动删除下载任务只清理该任务的临时文件和导出的 MP4；共用的播放缓存需在播放缓存页面单独删除。

## 构建

当前工作区复用同级 `FilmWord/.android-sdk` 和 `FilmWord/.gradle`，本目录 `.toolchain` 内有本地 JDK 21 与 Gradle 9.7.1。运行：

```powershell
.\build-mobile.ps1
```

调试 APK 输出到 `app/build/outputs/apk/mobileArm64_v8a/debug/`。安装包使用调试签名，包名为 `com.mydvd.app`。目前构建目标是 arm64 手机，电视界面仍随源码保留，但未针对电视适配下载入口。
